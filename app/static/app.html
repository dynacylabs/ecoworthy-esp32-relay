Edits esphome-victron-ble/secrets.yaml directly, then compiles and OTA-installs victron-mppt.yaml to the ESP32 using the esphome CLI, right from this container - no separate dashboard container needed. The very first build still has to download the ESP-IDF/PlatformIO toolchain (~1GB, one-time, needs internet access) - it's cached afterwards, so every build after that is much faster.
