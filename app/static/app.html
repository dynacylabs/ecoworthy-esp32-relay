Flashing new firmware, or changing the ESP32's WiFi/API/OTA credentials or the Victron SmartSolar's MAC/bindkey, is done through the official ESPHome dashboard below - not this page. It already handles editing secrets, compiling, and OTA-installing safely.

ESPHome Dashboard

Runs as a separate container (the esphome service in docker-compose.yml), pointed at esphome-victron-ble/. Use it to edit victron-mppt.yaml/secrets.yaml (WiFi, API encryption key, OTA password, and the SmartSolar's victron_mac_address/victron_bindkey), then compile and OTA-install the result straight to the ESP32, with live build logs in the browser. It has its own login, separate from this dashboard's token. Embedded below (dark themed to match this page - see firmware-proxy/), or open it in its own tab.

First-ever flash of a blank ESP32 still needs a USB cable (it has to be reachable on the network before OTA is possible) - see the README's "ESPHome setup" section. Every flash after that, including MAC/bindkey changes, can be done here over the air.
